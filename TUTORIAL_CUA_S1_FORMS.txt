LATAR BELAKANG NYATA: MENGAPA MODEL AI INI DIBUTUHKAN?
--------------------------------------------------------------------------------
Di lapangan, seringkali terjadi skenario nyata seperti ini:

1. KEBUTUHAN DI LAPANGAN:
   Petugas pendata di lapangan mengumpulkan data warga menggunakan aplikasi 
   formulir eksternal yang mudah diakses lewat ponsel, misalnya: Google Form, 
   KoboToolbox, JotForm, atau spreadsheet online.

2. KENDALA KEAMANAN SISTEM UTAMA:
   Di sisi lain, aplikasi sensus utama dan database kependudukan resmi berada 
   di server internal/jaringan kantor yang aman dan terisolasi. Aplikasi ini 
   TIDAK BISA dan TIDAK BOLEH diakses oleh sembarang orang dari internet bebas 
   demi menjaga kerahasiaan NIK, Kartu Keluarga, dan privasi warga negara.

3. MASALAH PEKERJAAN BERULANG (DATA RE-ENTRY):
   Akibat pemisahan sistem tersebut, petugas admin di kantor terpaksa harus 
   melakukan PEKERJAAN BERULANG yang melelahkan: membuka hasil unduhan Google 
   Form, lalu mengetikkan ulang ratusan baris data satu demi satu ke formulir 
   aplikasi sensus internal secara manual. Pekerjaan ini memakan waktu berhari-
   hari dan sangat rawan terjadi salah ketik (human error).

>>> INI ADALAH SOLUSINYA! <<<
Model AI CUA-S1-FORMS hadir sebagai solusi otomatisasi cerdas. Model AI ini 
bertindak sebagai robot asisten yang membaca berkas hasil Google Form/CSV, 
memahami sendiri kolom mana yang harus diisi, lalu mengisikan data ke aplikasi 
sensus internal dan menyimpannya ke database dalam hitungan detik secara akurat!

1. [KONSEP DASAR] APA YANG SEBENARNYA DILAKUKAN OLEH MODEL AI INI?
================================================================================
Bayangkan Anda memiliki seorang asisten kantor digital bernama "CUA-S1".

Tugas asisten ini:
1. Membaca lembar data warga hasil formulir eksternal (Google Form / CSV).
2. Membuka formulir pendaftaran warga di website sensus internal.
3. Mencocokkan sendiri kolom yang tepat secara cerdas:
   - Tulisan nama dimasukkan ke kotak "Full name".
   - Tanggal lahir dimasukkan ke kotak "Date of birth".
   - Nomor KK dimasukkan ke kotak "Policy # / No KK".
   - Alamat domisili dimasukkan ke kotak "Street address".
   - Jaminan kesehatan dimasukkan ke kotak "Insurance provider".
4. Setelah semua kotak terisi dengan benar, asisten AI ini secara otomatis
   mengeklik tombol "Submit" (Kirim Data).

AI ini bekerja menggunakan jaringan saraf tiruan (neural network). Dia tidak 
menggunakan aturan kaku 'if/else', melainkan membaca teks per karakter, 
menghitung tingkat keyakinan (misal: 100% yakin), lalu mengambil tindakan.

- requests        : Alat pengirim data dari AI ke website.

5. [LANGKAH 3] MENGUNDUH OTAK AI DARI INTERNET
================================================================================
Tujuan: Mengunduh file library dan bobot model AI resmi (ukurannya sangat kecil,
hanya sekitar 2.8 Megabyte, sehingga selesai hanya dalam hitungan detik).

BAGIAN A: Mengunduh Kode Program Pendukung dari GitHub
Ketik perintah ini di Terminal, lalu tekan ENTER:
cd /root/Desktop/aplikasi-sensus
git clone --depth 1 --filter=blob:none --sparse https://github.com/trycua/cua.git cua-repo
cd cua-repo
git sparse-checkout set libs/cua-s1
cd ..

BAGIAN B: Mengunduh File Bobot Model AI dari Hugging Face
Ketik perintah ini di Terminal, lalu tekan ENTER:
python3 -c "
from huggingface_hub import hf_hub_download
import os
print('Mengunduh model CUA-S1-FORMS...')
w = hf_hub_download('cua-ai/cua-s1-forms', 'cua-s1-forms.safetensors')
print('✓ Selesai! Ukuran file model:', round(os.path.getsize(w)/1024/1024, 2), 'MB')
"

HASIL YANG BENAR DI LAYAR:
✓ Selesai! Ukuran file model: 2.82 MB

8. [LANGKAH 6] CARA MEMERIKSA HASILNYA DI LAYAR ANDA
================================================================================
Anda bisa melihat hasil kerja AI melalui 3 cara mudah:

CARA 1: MELALUI WEBSITE SENSUS (Tampilan Paling Mudah Dilihat)
1. Buka browser Google Chrome di komputer Anda.
2. Buka link: http://127.0.0.1:8000/data.php
   - Anda akan melihat tulisan: "Menampilkan data (Total data: 200)".
   - Anda bisa mencoba mengetik nama warga di kolom pencarian.
   - Anda bisa mengklik tombol hijau "Detail" di kanan untuk melihat 28 kolom 
     lengkap data warga tersebut.
3. Buka link grafik: http://127.0.0.1:8000/statistik.php
   - Menampilkan diagram warna-warni sebaran umur, jenis kelamin, dan pendidikan.

CARA 2: MELALUI PHPMYADMIN (Melihat Database Asli MySQL)
1. Buka link: http://127.0.0.1:8000/phpmyadmin/
2. Di kolom sebelah kiri, klik database: "db_sensus" -> klik tabel: "penduduk".
3. Klik tab "Jelajahi (Browse)" di bagian atas.
4. Anda akan melihat 200 baris data tersimpan rapi di dalam tabel MySQL.

CARA 3: MELALUI SPREADSHEET (File CSV)
1. Lihat di Desktop komputer Anda.
2. Klik dua kali ikon "Buka Spreadsheet Sensus (Gnumeric)".
3. Aplikasi spreadsheet ringan (Gnumeric) akan terbuka dan menampilkan data CSV.

9. [LANGKAH 7] PERTOLONGAN PERTAMA JIKA ADA MASALAH (TROUBLESHOOTING)
================================================================================
Jika komputer sempat dimatikan atau website tiba-tiba tidak bisa dibuka:

MASALAH 1: Website http://127.0.0.1:8000/ tidak bisa diakses
Solusi: Jalankan kembali server PHP dengan perintah:
nohup php -S 0.0.0.0:8000 -t /root/Desktop/aplikasi-sensus > /dev/null 2>&1 &

MASALAH 2: Database MySQL mati
Solusi: Jalankan kembali database MySQL dengan perintah:
nohup mariadbd --user=mysql > /dev/null 2>&1 &

SOLUSI ALL-IN-ONE (1 PERINTAH UNTUK MENYALAKAN SEMUANYA):
Ketik di Terminal:
bash /root/Desktop/aplikasi-sensus/start.sh
